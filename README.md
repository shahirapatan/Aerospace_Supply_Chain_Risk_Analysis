# Aerospace_Supply_Chain_Risk_Analysis
Analyzed 300 aerospace parts across supplier performance, criticality, delivery delays, fill rate, quality incidents, and scrap to identify supply-chain risk areas. Evaluated risk distribution by part criticality and supplier delivery performance, identifying high-risk parts, late purchase orders, and suppliers requiring attention. .
Built an interactive Excel dashboard using Pivot Tables, charts, filters, conditional formatting, and KPI analysis to monitor risk levels, quality issues, supplier performance, and scrap across part families.
