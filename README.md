# Aerospace_Supply_Chain_Risk_Analysis

Analyzed 300 aerospace parts across supplier performance, criticality, delivery delays, fill rate, quality incidents, and scrap to identify supply-chain risk areas.

Built an interactive Excel dashboard using Pivot Tables, charts, filters, conditional formatting, and KPI analysis.

## Tools
- Microsoft Excel
- Pivot Tables
- XLOOKUP
- Data Analysis
- Data Visualization
- Conditional Formatting
