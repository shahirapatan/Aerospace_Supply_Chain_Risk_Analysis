# Aerospace_Supply_Chain_Risk_Analysis
Analyzed 300 aerospace parts across supplier performance, criticality, delivery delays, fill rate, quality incidents, and scrap to identify key supply-chain risk areas.
Built an interactive Excel dashboard using Pivot Tables, charts, filters, conditional formatting, and KPI analysis to monitor risk levels, supplier performance, delivery issues, quality incidents, and scrap.
Tools: Microsoft Excel
Skills: Data Analysis, Data Cleaning, Pivot Tables, XLOOKUP, KPI Analysis, Data Visualization, Conditional Formatting
